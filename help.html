Help Center

Need assistance navigating games, loading records, or configuring features? Find answers to frequently asked questions below.

Scores, game states, and Personal Best (PB) records are automatically stored in your local browser using localStorage. There are no registration pages or online user accounts. As long as you play using the same browser on the same device, your records will be saved.
Since all mini-games run client-side in your web browser, performance depends on system resource availability. To resolve lag:
  • Close other heavy background browser tabs.
  • Ensure that hardware acceleration is enabled in your browser settings (e.g., in Chrome: Settings > System > Use hardware acceleration when available).
  • For physics-based simulation models like Structural Engineer, consider running in standard view mode rather than spamming structural analysis loops.

For typing challenges or heavy simulations, we recommend using a desktop viewport for the best physical control input.
